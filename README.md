# 米游社资讯推送

> 插件识别名：`astrbot_plugin_miyoushe`

为 [AstrBot](https://github.com/Soulter/AstrBot) 提供米游社官方资讯推送能力。支持定时轮询 **原神、崩坏：星穹铁道、绝区零、崩坏三、崩坏二、未定事件簿** 等游戏的公告与资讯，并自动推送到指定群聊。

- **定时推送**：采用「文字 + 封面」富文本卡片（标题 / 摘要 / 发布时间 / 链接，每条公告一条消息）。
- **链接解析 / 公告详情**：改为 **AI 总结**（标题 + AI 总结 + 发布时间 + 链接），需要配置支持图片输入的视觉模型；配图与正文默认**不限制**（全部传入）。
- **帖子搜索**：纯文字列表 / 单条纯文字（标题 + 时间 + 文章自带摘要 + 链接），不调 AI。

### 核心能力

- **自动推送** — 定时轮询米游社 API，新公告/资讯自动推送，支持去重、关键词过滤
- **富文本卡片** — 每条公告推送为一条图文消息：标题 + 摘要 + 发布时间 + 链接 + 封面图
- **AI 总结** — 链接解析、公告详情调用 LLM（可带文章配图）生成要点总结；失败自动回退文章自带摘要
- **视觉模型引导** — 模型不支持图片输入时自动降级为纯文字总结，并提示在 WebUI 选择支持视觉的模型
- **多类型覆盖** — 支持「公告」和「资讯」两种内容类型，均支持列表查询和序号查询
- **帖子搜索** — `#米游社 关键词` 返回纯文字列表（前 10 条），`#米游社 关键词 3` 查看单条纯文字，不调 AI
- **URL 解析** — 发送米游社文章链接自动 AI 总结，支持标准链接和移动端分享链接
- **活动预警** — 监测游戏内即将结束的活动，每日轮询一个群发送提醒
- **多平台适配** — 支持 aiocqhttp、QQ Official、Telegram、微信等消息平台

## 功能

- 定时轮询米游社官方公告/资讯并推送到群
- 定时推送为富文本卡片：标题 + 摘要 + 发布时间 + 链接 + 封面图（每条公告一条图文消息）
- 链接解析 / 公告详情：标题 + AI 总结 + 发布时间 + 链接（不生成图片）
- 帖子搜索：纯文字列表（前 10 条）/ 单条纯文字（文章自带摘要），不调 AI
- 支持多游戏：原神、崩坏：星穹铁道、绝区零、崩坏三、崩坏二、未定事件簿
- 支持两种推送类型：公告、资讯
- 公告列表（`#原神公告列表`）为文字列表：标题 + 时间 + 链接（不调 AI）
- 支持序号查询、列表模式、帖子搜索、URL 自动解析
- 活动到期预警（每日轮询）
- 多平台支持：aiocqhttp、qq_official、telegram、weixin_oc
- 推送降级：富文本卡片发送失败时降级纯文字（无封面）；AI 失败降级文章自带摘要 + 提示

## 命令

| 命令 | 说明 |
|------|------|
| `#原神公告` | 查看最新一条公告（AI 总结） |
| `#原神公告3` | 查看第 3 条公告（AI 总结） |
| `#原神公告列表` | 查看公告列表（标题 + 时间 + 链接，不调 AI） |
| `#崩铁资讯` | 查看最新一条资讯（AI 总结） |
| `#米游社 关键词` | 搜索米游社帖子：纯文字列表（默认前 10 条，不调 AI） |
| `#米游社 关键词 2` | 查看第 2 条：单条纯文字（标题/时间/摘要/链接，不调 AI） |
| `#开启原神公告推送` | 开启公告推送（群管理员） |
| `#关闭崩铁资讯推送` | 关闭资讯推送（群管理员） |
| `#开启原神活动预警` | 开启活动到期预警（群管理员）|
| `#推送原神公告` | 手动触发推送（Bot 管理员）|
| `#米游社推送` | 查看帮助 |
| 发送文章链接 | 自动 AI 总结文章内容 |

> 支持的游戏名：原神、崩铁/星铁、绝区零、崩坏三/崩3、崩坏二/崩2、未定/未定事件簿

## 安装

在 AstrBot 中通过插件市场安装，或手动将本仓库克隆到 `data/plugins/` 目录：

```bash
cd data/plugins
git clone https://github.com/makotowu/astrbot_plugin_miyoushe
/plugin reload
```

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `proxy` | string | "" | HTTP 代理地址 |
| `push_interval` | int | 300 | 轮询间隔（秒）|
| `push_window` | int | 7200 | 新资讯推送时间窗口（秒）|
| `max_push_per_round` | int | 2 | 每轮每个游戏+类型最大推送条数 |
| `push_summary_len` | int | 100 | 推送卡片摘要截取字数，0 表示不带摘要 |
| `ai_summary_enable` | bool | true | 链接解析/公告详情是否使用 AI 总结（搜索始终纯文字、不调 AI） |
| `ai_summary_provider_id` | string | "" | AI 总结使用的模型 ID；留空用当前默认模型。**请选择支持图片输入的视觉模型** |

> **AI 总结不设上限**：正文全文 + 文章内全部配图都会传给模型（已无配图数量/字数配置项）。
>
> **AI 总结需要视觉模型**：请在 WebUI 的「服务提供商」中配置一个支持图片输入（多模态）的模型，并把
> `ai_summary_provider_id` 填成它的 ID（如 `deepseek/deepseek-flash`）。留空则使用当前默认对话模型；
> 若默认模型不支持图片输入，插件会自动降级为纯文字总结（仍可用），但无法总结配图。
>
> 若默认 provider 的令牌过期/不可用，请在配置中显式指定可用的视觉模型。

## 架构

```
main.py          → 主入口、命令注册、定时轮询、富文本推送、AI 总结输出
ai_summary.py    → AI 文章总结（视觉模型调用、摘要/正文/配图提取、失败回退）
mhy_client.py    → 米游社 API 客户端（只读）
constants.py     → 游戏/类型常量映射
data_store.py    → 推送配置持久化
dedup_store.py   → SQLite 去重存储
```
